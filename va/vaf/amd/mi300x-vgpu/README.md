# VA: AMD Instinct MI300X vGPU (GIM SR-IOV)

If you are looking for information on how to deploy the AMD MI300X vGPU VA, then
please see the
[AMD MI300X vGPU README in the examples directory](../../../../examples/va/vaf/amd/mi300x-vgpu/README.md).

This directory, `architecture/va/vaf/amd/mi300x-vgpu/`, exists so that the
[kustomization.yaml](../../../../examples/va/vaf/amd/mi300x-vgpu/kustomization.yaml)
in the examples directory for this VA can reference it by path as a component.
Its contents are likely uninteresting unless you want to understand how kustomize
was implemented in this repository.
